# Time Desk 0.5.1

## 修复

- 普通任务到达安排日期后，只要仍未完成，就继续出现在后续日期的当天待办，不再全部隐藏到“之前未完成”折叠区。截止日无论在当天、未来或已经过去，都不会使未完成任务从执行清单消失。
- 过去带时间的任务也进入当天待办，标注“延续自”与原安排时间，不改成当天的新预约。
- 当天重点与续办列表去重；昨天的重点标记不会自动占用今天的重点名额。
- 续办任务在当天完成后进入已完成区，撤销完成后回到当天待办；原安排日期、截止日期和发生标识保留。
- 截止提醒中的旧日期增加“原安排”标识，避免与截止日混淆。
- 尊重单次改期到未来，以及完成／跳过／取消／删除状态；超过日历查询窗口的旧普通任务仍可延续。

## 重复事项与习惯

完成后间隔型任务只延续当前未完成周期。固定日历重复仍按每次发生日独立记录，历史未完成的重复事项单独折叠；习惯不累积昨天的额外次数。

## 数据与升级

这是筛选和显示规则修复，没有数据结构迁移，不通过批量修改日期实现延续。已有任务、专注记录、习惯和助手会话存储保持原有标识。升级后刷新页面查看。

## 验证与限制

新增跨日延续、定时任务、未来改期、超过一年旧任务、关闭状态、重点去重、完成撤销与重复周期等回归测试。使用虚构数据测试，不在源码或分发包中包含用户任务与截图。

界面实际观感仍需客户端交互确认；这次不改变用户侧升级机制。
