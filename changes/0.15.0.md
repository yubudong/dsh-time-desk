# Time Desk 0.15.0

- 习惯页默认日视图：所选日待完成在前、已完成默认展开并淡化标题，显示完成数/当日总数。跳过及未达成、昨天待完成独立展示，不混入今日完成数。去掉逐行重复的七日日期，将规则编辑收进更多菜单。
- 周视图显示全部习惯×周一至周日的打卡表，支持左右切周；月视图选择单个习惯，显示当月完成天数、每日状态及数量/时长进度，支持跨月查看。日期边界按工作台时区与现有规则计算。
- 周次数目标单独展示，只有安排在所选日的待办或实际完成才进入日统计；休息间隔、次日完成、补记和复盘关联继续使用原有记录入口，不重写规则。
- 明确区分按时完成、补做、部分完成、待完成/过去未记录、跳过、未达成、不安排、休息、未来和周目标未安排。未来不可打卡；历史日志保留可见，非安排日不提供新增记录操作。未完成不自动标记未达成。
- 8项新回归覆盖日分组与周次数隔离、休息及计划、数量累计/撤销、状态差异、次日完成窗口、周月边界/闰年、暂停后历史及删除记录。
- 类型检查、构建、280项测试、真实DSH存储/HostConnection合成验证与默认日视图服务端渲染检查通过。
- 本轮只更新本机，不公开发布。没有使用真实习惯作写入测试；浏览器实机布局及点击尚未自动验收。
