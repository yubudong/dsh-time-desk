# 第二版首批验收：0.7.0

范围：升级与恢复可靠性收尾、快速收集、收件箱整理、今日计划。后续项目里程碑、时间段冲突和行动型复盘不在本批。

## 已有证据

- TypeScript 校验、Host/Client 构建和自动测试。
- 合成数据验证：延续任务挑选与移回不改日期、截止或发生标识；负荷去重、未估时独立计数；每日可用时间区分零与未设置；改到未来后不在当天计量；计划随备份恢复和持久重开保留。
- 快照验证：异步读取、持久化失败不污染内存、运行版本来源、预检后 revision 变化、Host 助手忙碌、UTF-8 大小限制、恢复成功后元数据失败单独报告。
- 真实已安装 DSH 的 JSON Storage 与 HostConnection，使用独立临时单元与合成数据：准备快照→恢复→持久重开；UI 路由与 Agent 工具读取相同每日计划。测试临时目录在结束时检查绝对位置后清理。

## 交互源码复核

当前没有可调用的浏览器控制／截图工具，也没有可调用的子代理委派工具。本次由主代理进行源码层面的 UX 复核，没有伪造浏览器或模拟页面结果。

已处理的发现：

- 原设置页未传递升级区块的完整属性：补齐并用明确必需类型约束，防止再次遗漏。
- 新增入口保持在滚动区外；快速新增面板限制高度并独立滚动，窄屏允许工具栏换行。
- 快速记录保存失败保留草稿；保存中禁用输入，避免清空请求期间新增的文字；快捷键仅在工作台获得焦点时响应，不接管 DSH 全局快捷键。
- 轻量归类后未设日期的任务保留在“已归类 · 未安排”，避免从待整理区消失后失去入口。
- 负荷文案明确只有已估算部分可比较，不将未知当成零。
- 样式复用 DSH／工作台主题变量，不引入固定浅色背景；源码检查不能证明真实深浅色效果。
