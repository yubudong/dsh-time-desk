# Time Desk 0.16.2

本次公开版累计包含 0.13.0 之后的 0.14.x、0.15.0、0.16.0 与 0.16.1 本机更新。

## 任务与日历

- 延续待办支持拖动标题或把手到「计划待办」，加入当前所选日期；空列表及折叠计划区也可接收，保留加号和移回入口，不改原安排日或截止日。
- 修复重复任务本次完成后仍出现在截止提醒的问题，撤销后恢复，其他周期不受影响。
- 日历已完成事项显示小勾并淡化文字和背景；月视图优先显示未完成，周／日保持时间顺序。习惯按实际达标记录、课程按确认上课记录标记，不因日期过去自动完成。

## 习惯、生活与课程

- 习惯默认日视图分组待完成和已完成；周视图统一七日表，月视图选择单习惯看记录与累计量。周次数目标、昨天待完成、休息间隔和次日完成窗口单独处理，未来不能提前打卡。
- 生活默认日清单，分开完成状态、提醒、以前未完成及未安排事项；支持周／月安排和全部事项／重复规则管理。
- 课程支持日、周、月及独立课程管理入口，保留课时包、年卡、人员筛选、课次历史与账本。查看和切换视图只读。
- 课程操作统一为「确认上课」，与「待上课／已上课」状态区分；未来课次不显示灰色确认按钮。首页和课程日视图增加更多菜单，复用原调课、请假、撤销和详情弹窗，保留扣费及冲突确认。

## 项目与时间精灵

- 项目展示目标、任务进度、截止与下一步；可指定下一步，也可自动建议。任务全完成后由用户确认项目目标，不自动完成项目；归档可逆，不删除或取消任务。
- 项目新增可选下一步与归档元数据，旧项目默认值兼容，随本版备份保存。有日期任务继续与今日、日历共享状态，未安排任务留在项目中。
- 「请时间精灵帮我复盘」直接打开右侧现有助手，带入所选日期、模板和已有内容供用户发送，保留编辑器草稿，不自动发送、保存或打卡。
- 模型选择移到输入框右下角、发送／停止按钮旁，紧凑显示模型和提供方名称，保留默认跟随、分组、刷新、键盘选择和完整标识提示。输入、生成与会话流程保持不变。

## 验证与分发

- 类型检查、Host／Client 自包含构建、290项回归及隐私检查通过；真实DSH存储与HostConnection合成业务验证通过。React继续使用DSH运行时，不增加原生依赖或安装生命周期脚本。
- 仅分发公开源码与预构建资源，不包含个人任务、课程账目、习惯记录、助手对话、备份或凭据。
- 已做源码层面可用性检查；未完成浏览器实际视觉、明暗主题和交互验收，不将自动测试描述为实机验收。
- GitHub Release、npm与市场同步分别核验；市场独立审核与定时索引刷新不等于本次发行已完成收录。
