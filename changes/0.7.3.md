# Time Desk 0.7.3

习惯更简单：去掉时段分组，加入可选模板和明确的“怎样算完成”。

- 今日习惯改为平铺列表，不再显示“不限／晚上”分组标题，也不在行内重复时段。习惯的添加与编辑表单移除“时段”字段；旧数据里的该字段保留，不再参与界面分组。
- “添加习惯”先给出可选模板：阅读、运动、早睡、每日复盘、每周复盘，另有自定义。模板只预填名称、频率与说明；确认保存前不会创建任何习惯，也不会自动设置提醒。
- 每日复盘模板默认关联日复盘；表单把它收进“怎样算完成”：手动打卡／保存当天日复盘后自动完成。只有每天一次的习惯能选后者。
- 每周复盘模板目前是每周目标 1 次的手动习惯，界面明确说明保存周复盘不会自动完成它。
- 移除习惯编辑器里单独的“关联复盘”折叠开关，避免与频率设置分散。
- 不改变既有习惯、打卡记录、计划、计时或备份格式。

验证：类型检查、构建、156 项回归测试。新增测试覆盖模板生成、只填表单不落库、完成方式区分、日复盘只自动完成日习惯。没有浏览器控制工具，模板弹窗、单选与平铺列表的实际显示仍待页面验收。
