# Time Desk 0.12.1

- 精灵打开时的番茄钟移到真正的顶部工具栏，在搜索与右侧操作之间显示。移除内容滚动区中的吸顶计时条，避免遮住计划和习惯内容。
- 顶部显示紧凑的状态、任务/自由专注名称、剩余时间和主要操作；时长、表盘、全屏及统计收入“···”菜单，点击后展开。
- 计时结束时只保留确认记录和更多入口，不再显示无用的禁用暂停按钮。确认记录、取消恢复和实际计时保存逻辑沿用原实现。
- 更多菜单支持Escape关闭和点外部关闭，进入设置面板时移动焦点；结束确认保持显式保存或取消，不因点外部自动结束。
- 工作区宽度不足时，在顶部工具栏内部换到第二行；更窄时再换行主要控件。与精灵、副工作台拖动调宽共存，不使用整窗宽度猜测中间区域空间。
- 精灵打开或窄屏使用顶部计时器时，副工作台中的整块计时模块隐藏，不留下重复标题或空白；关闭精灵后的宽屏首页仍可用原侧栏计时卡。
- 尊重首页计时模块的隐藏/折叠设置。没有修改计时、专注日志、习惯、课程或课时数据。

验证：255项既有测试、类型检查、构建、真实DSH存储/路由回归及隐私检查。没有可控制浏览器的工具，实际一行/两行布局、菜单焦点与窗口拖动后的观感仍需页面验收。仅本机更新，未公开发布。
