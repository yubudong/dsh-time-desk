# Time Desk 0.7.0

第二版产品首批：快速收集、收件箱整理与今日计划。本版先本机验收，是否公开发布由用户另行决定。

## 快速新增

顶部常驻入口，工作台获得焦点时可按 ⌘/Ctrl+Shift+K 打开。只填标题存入收件箱；展开后可选择项目、领域、安排日、截止日、预计分钟和番茄数。保存成功才清空，可继续新增；失败保留草稿，网络重试复用同一请求标识。Esc 收起时保留本次页面草稿，刷新或重载不保证草稿保留。保存时禁用输入，避免在保存期间输入的新内容被清空。

## 收件箱整理

未设日期、未分配项目且领域仍为 inbox 的未完成事项计入待整理数量。可在卡片内选择项目／领域、日期、截止日和估时；保存走原业务校验和记录版本校验。已归类但未安排的事项仍在下方，归类不会使它们失去入口。

## 今日计划

- 当日重点、定时安排、计划待办、延续待选、已完成分别展示。
- 安排在当天的未完成事项自动计入计划。延续事项默认留在待选区，加入某日计划只保存当天的选择，不改任务、安排日、截止日或原发生记录。
- 取消重点只清 priorityDate；移回延续待选只移除当日选择，不改期、不完成任务。
- 可用时间按日期独立保存，默认未设置；零分钟是有效输入，清空表示取消设置。
- 分钟估时优先，其次按番茄数乘当前默认专注分钟；重点与定时安排去重。未估时项独立计数，不当作零分钟，负荷提示仅对已估算部分成立。
- 已记录专注包含当天保存的完整与部分专注记录，不含运行中尚未保存的秒数。待办完成后不再计入剩余计划负荷。
- 追加兼容字段 dayPlans，旧数据默认空数组，备份导出／导入继续包含计划。时间精灵用 action=plan command=read 读取相同业务结果，批量安排仍先预览并确认，不猜可用时间。

## 0.6.0 可靠性收尾

- 修复设置页没有将快照请求和状态传入升级区块的问题；升级区块改用明确的必需属性类型，防止同类遗漏再次通过类型检查。
- 快照只有持久化成功才更新内存状态。读状态支持异步，关闭等待已排队操作。
- 上限按 UTF-8 字节计，快照 ID 使用 UUID；界面只显示活跃记录数量。
- 从 Host 当前运行版本填写来源版本；预检返回 revision，创建快照再次核对。助手忙碌由 Host 复核，客户端包含后台 busy 状态。
- 工作台数据已经恢复而提示元数据保存失败时，明确返回“数据已恢复”的警告，避免误判恢复失败并重试覆盖新数据。

## 验收界限

测试只使用合成数据。通过自动测试、真实 DSH 存储与路由检查，不等于完成实际点击验收。

当前工具没有浏览器控制能力；以下仍需在已安装页面操作：快速新增与快捷键、窄屏／深浅色布局、长页面滚动后入口、收件箱归类、延续任务挑选与移回、未估时／超载提示、升级准备跳转和恢复确认。

未实现跨窗口未保存表单检测、全局升级锁、自动安装、插件代码版本回滚。主存储 revision 冲突保护继续生效，升级快照仅恢复工作台业务数据。
