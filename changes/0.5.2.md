# Time Desk 0.5.2

## 修复

- 将包含时间精灵、搜索与心情选择的顶部操作栏移出正文滚动区域，长页面滚到底部时仍可打开助手。
- 工作区采用独立操作栏与可滚动正文两行布局，操作栏自动换行时由布局预留空间，不覆盖任务和表单。
- 顶部计时条在正文滚动区内吸附，不再使用负偏移，与固定操作栏分层显示。
- 保留助手窄屏抽屉层级、搜索与心情选择的响应式布局；为操作栏声明非原生窗口拖动区域。

## 数据与升级

本次只调整界面结构与样式，没有数据结构迁移，不修改任务、习惯、日期、专注计时或助手聊天存储。更新后刷新页面查看。

## 验证与限制

检查 JSX 布局与响应式规则，执行类型、构建和已有自动测试。当前没有真实浏览器控制，长页滚动和不同宽度下的最终视觉效果仍需客户端交互确认，不用源码检查冒充截图验收。
