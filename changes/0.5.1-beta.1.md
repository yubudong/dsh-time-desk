# Time Desk 0.5.1-beta.1

本版本用于第一期自动发版流程验收，不替代稳定版 Latest，不向市场稳定入口推广。

## 新增

- 版本标签触发检查、预构建归档、摘要校验、草稿上传与完整性核对后的公开发布。
- 支持中断后补传草稿附件；重复运行已公开版本仅核验，不覆盖附件。
- 市场材料独立生成；没有专用投稿凭据时提供明确的人工提交材料。

## 数据与升级

没有工作台业务功能或存储结构变化。该测试版在独立发布 worktree 中构建，不自动安装到开发者或其他用户的 DSH Profile，也不读取个人任务与聊天。

## 验证与限制

本地类型检查、105 项自动测试与隐私检查通过；将以本标签验证 GitHub Actions 的完整发版、测试通道和不可覆盖重跑行为。工作流实际执行结果见对应 Actions 运行。

这不是用户侧自动升级功能。系统通知、不同客户端原生全屏和 UI 实机体验仍需单独验证。
