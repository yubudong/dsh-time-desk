# Time Desk 0.12.0

## 时间精灵

- 移除普通对话提示词中“只处理时间工作台”的职责限制，明确支持一般知识问答、分析、讨论和建议。讨论不自动转成排期或保存操作。
- 普通精灵不再额外施加仅允许 life_desk 的工具白名单；可用工具和权限取决于 DSH 宿主环境，不虚构联网、文件或执行能力。
- 原有对话、模型选择和工作台记录保留；提示词明确旧对话中仅安排记录的限制已不适用。
- 专用“辅助复盘”流程仍保留仅提交候选草稿的隔离，用户确认后才保存正式记录。
- 更新欢迎语与输入提示，仍要求如实返回执行结果，并遵从用户的数据修改授权。

## 面板宽度

- 主工作区与副工作区之间、副工作区与精灵面板之间增加12px鼠标命中区域，悬停显示细线和横向调整光标。
- 拖动向左扩大右侧面板，向右缩小；两处宽度独立存入本机浏览器，不修改工作台 revision。
- 键盘方向键每次10px，Shift+方向键40px，Home/End取当前边界，双击或Enter恢复默认；Esc或指针取消恢复本次拖动之前的宽度。
- 按实际可用空间限定最大宽度，保留主工作区最小空间；窄屏副工作台移到下方并隐藏不适用的竖向拖动条，精灵变成仍可调宽的浮动侧栏。
- 宽度偏好不包含个人业务数据，不进入JSON备份；浏览器禁用存储时仍可在本次页面内调整。

## 验证

- 255项测试，包括普通精灵无额外工具白名单、复盘隔离仍保留、提示词允许一般分析，以及宽度持久值校验、桌面与窄屏边界计算。
- TypeScript、Host/Client构建、真实DSH存储与HostConnection既有业务回归、隐私检查。
- 当前无浏览器交互控制，拖动手感、键盘焦点和不同窗口宽度下的实际排版仍需页面验收。没有向用户聊天发送测试消息或调用模型生成测试回复；模型实际回答不以提示词测试代替验证。
- 仅本机安装，未推送GitHub、npm或插件市场。
