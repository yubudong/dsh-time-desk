# Time Desk 0.11.0

新增每周次数习惯的可选休息间隔、建议日期和温和进度预警。仅本机更新，不公开发布、不接入同步。

## 规则

- 周一至周日是一周，完成次数按不同日期计数，同一天重复记录不会增加第二次。
- 每周规则新增 `restDays=0–6`，默认0，不限制间隔；新增 `weeklyHints`，默认显示进度建议，可在编辑习惯时关闭。
- 休息按工作台时区的自然日计算。完成后休息1天表示周一完成、周二休息、最早周三再安排；周日完成后的休息延续到下周，不因周一重新计周目标而清零。
- 按每个日期的生效规则计算，旧规则和实际记录保留。不根据习惯标题自动给所有同名习惯设置间隔。

## 首页与实际记录

- 周目标进度显示为“1/3次”，同时说明按不同日期计数和休息间隔。
- 用实际完成日和本周剩余有效日期搜索可行安排，避免将休息日也算作可完成机会。刚好够完成或已不足时显示小号语义警示色提示，不弹窗催促、不发送新系统通知。
- 周五还差3次、休息1天时，最多只能安排周五和周日两次；周四刚完成时，周五休息，本周最多再安排周六一次。
- 已有可兼容计划作为预测约束，再选择较早的可用日期。不会为了凑够目标而忽略或替换已安排日期；比如周三尚未完成、已安排周四、休息1天，本周最多再安排2次，而不擅自改成周三/周五/周日。已明确跳过/未达成的日期不算可用；过去没有完成的“计划”不会被当作实际训练来触发休息。
- 提供安排今天、安排下次和本周计划查看/取消。计划不产生打卡；本周不足不会自动降低目标，也不会将欠次数累积到下周。
- 可点周目标的习惯名称记录实际完成。休息间隔不一致（包括补记导致与后一次训练冲突）时，必须勾选确认实际已经完成，仍允许如实记录。撤销后重新计算建议；未来日期仍不能提前打卡。
- 休息日不自动标记跳过、未达成或失败。完成目标后预警消失。历史周不显示进度催促；未来预览不显示当下预警。
- 规则变更后，旧计划可能不再合适；提示核对而不自动删除，仍可取消已暂停或已改变规则日期上的旧计划。

## 数据与助手

- 旧规则默认间隔为0、建议开启，旧备份可读取；新字段随主数据备份与恢复保存。新版备份需使用本版或后续兼容版本恢复。
- `plan command=habits` 是只读查询，返回指定周的目标、实际完成、容量、建议、已有计划和冲突，不改变 revision。
- `habitLog confirmRest=true` 仅在用户明确确认实际完成或冲突计划后使用，助手不能代为确认；规划不会增加完成次数。
- 规则和建议属于安排辅助，不替代用户对训练强度或休息的决定。

- 使用真实 DSH 存储与 HostConnection 路由验证间隔确认、实际连续记录、只读预测、备份恢复和重开后的间隔规则。
- 类型检查、Host/Client 构建、隐私检查；测试使用合成记录，未将用户任务、打卡或截图写入源码。
- 实际窄屏换行、键盘焦点、复选框和颜色观感仍待页面交互验收，不能由上述自动测试代替。
