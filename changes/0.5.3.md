# Time Desk 0.5.3

第二期 A：让用户看得见版本、查得到新版，并能判断是否适用。**不包含自动下载或自动安装。**

## 新增

- 「设置与备份 → 版本与更新」显示当前版本、安装方式、当前 DSH 版本和上次检查时间。
- 手动检查更新；只读取项目 GitHub 的公开稳定版发布，不读取预发布版。
- 可选自动检查，默认关闭；开启后最多每天一次，只在工作台运行时发起，失败不弹窗。
- 发现新版时展示更新说明、发布时间、声明兼容范围，并提供「查看更新说明」「前往插件管理」和「忽略此版本」。
- 忽略只影响单个版本，可随时恢复提醒。
- 页面底部显示当前版本；有新稳定版时出现低调「有更新」标记，点击跳到版本区块。

## 判断规则

- 只接受自己仓库的正式 Release，草稿、预发布、外链、缺失安装包或缺失校验值的发布都会被拒绝。
- GitHub API 对未认证请求按 IP 限流（60 次/小时）。实测受限时回退到项目 Release 订阅，只取同一仓库的稳定条目；此时界面明确标注「安装附件未核对」，并仍通过固定标签读取兼容范围，不冒充已校验。
- 发布说明按纯文本展示，去掉 HTML 与脚本，长度受限。
- 已知当前 DSH 版本时，按发布声明的 `engines.dsh` 给出兼容／不兼容判断。
- 无法读取 DSH 版本或范围无法解析时，明确显示「无法确认兼容性」，不显示为可安全升级。
- 本地开发目录安装会被标注，界面不会声称从这里更新。

## 数据与隐私

检查偏好和结果缓存保存在独立单元 `life_desk_update`，不写入任务数据，不改变工作台 revision。检查只发送对 GitHub 的 GET 请求，不带任务、聊天、备份或模型凭据。缓存包含版本号、说明与校验值，不含个人信息。

## 边界

没有实现：一键升级、自动下载安装、升级前快照与运行中状态拦截（属于第二期 B）。工作台不会修改 DSH Profile 或插件文件，升级仍需用户在插件管理器确认。市场与 GitHub 的发版状态是两件事，这里只检查 GitHub 发布。

## 验证

新增版本比较、兼容范围、发布校验、说明清洗、状态区分、偏好持久化、冷却与网络失败等测试。界面滚动与真实点击仍需客户端交互确认。
