# Time Desk 0.5.1-beta.2

自动发版第一期的测试通道验收版本，不替换稳定版 Latest，也不推广到市场稳定入口。

## 修复

- 修正 GitHub 的标签查询接口不返回草稿导致的最终状态复核失败。
- 草稿通过认证后的 Release 列表查找，公开前按 Release ID 复核标签、来源与通道，避免重复创建草稿。

## 数据与升级

本次只验证发布自动化，没有工作台业务功能或数据结构变化，不自动安装到用户设备。不读取个人任务、对话、备份或模型凭据。

## 验证与限制

本地 108 项测试通过，包括草稿发现、部分上传恢复、不可覆盖重跑、摘要冲突、版本门禁和市场授权缺失降级。实际自动发版与重跑结果以本标签对应 Actions 为准。

此前测试在失败时保持草稿，没有误公开不完整版本。此版本继续验证完整附件核对后的公开步骤；用户侧升级提示和安装属于第二期，本期未实现。
