# Time Desk 0.16.0

## 生活

- 默认日视图，分开所选日待完成、已完成和纯提醒；以前未完成、过去重复事项、截止提醒、未安排日期各有入口。未安排事项和生日提醒不计入当天完成进度。
- 周／月视图按原发生实例显示时间、名称与完成标记，点击沿用单次编辑；全部事项入口管理主记录及重复规则。筛选领域和标签沿用旧逻辑。
- 新增生活事项默认带所选日期，用户可清空；常用模板折叠，减少默认页面重复信息。不因切换视图改期或新增计划。

## 课程

- 默认日视图按待上课、已上课、请假／取消分组；周、月和课程管理独立切换，管理入口始终可见。余额、课时包、年卡和课程详情原有操作保留。
- 课次展示保持原始发生身份，调课跟随新日期并标记来源；人员筛选作用于课表及余额／到期提醒。确认上课继续沿用原单次模态框，未来课次不可提前确认。
- 查看、切换和筛选只读，扣减、撤销返还、调课、请假继续由原业务接口执行。

## 项目

- 列表按当前、已完成、已归档分组，展示目标、进度、截止与下一步；详情保留列表／看板，任务待完成与已完成分组。
- ProjectInput新增默认空的nextTaskId、默认false的archived字段，旧状态todo/doing/paused/done保留；新字段随现有备份与服务存储往返。指定下一步必须属于同一未删除项目任务，失效或完成后显示其他建议，不改写真实任务。
- 自动建议优先进行中，再按截止／安排日；重复系列本次完成后建议下一次，不把整组或项目自动设为完成。
- 清单全完成仅提示，由用户点击确认项目目标。归档是可逆标记，不删除或取消任务；有日期的任务继续在今日和日历共享状态，未安排任务留在项目中。

## 验证

- 新增10项回归：生活分组与标签、未安排与提醒、延续挑选、完成／截止／日历同步、月度独立、旧项目默认、项目确认、下一步选择与失效、跨项目保护、归档保留、重复下一期、课程账本只读／撤销／调课／请假和项目元数据重开与序列化保留。
- 类型检查、构建、290项测试与真实DSH存储/HostConnection合成回归通过。
- 使用合成记录，不以用户真实项目或课程进行写入测试。进行一次源码层面的UI/UX自检：补齐新增生活日期默认值、下一步日期、筛选提醒及可键盘访问的横向周月视图。
- 无浏览器控制工具，不模拟DOM或另开浏览器；视觉、明暗主题与实际点击尚未验收。本轮仅更新本机，不发布GitHub/npm或市场。
