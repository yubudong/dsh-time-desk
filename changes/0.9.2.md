# Time Desk 0.9.2

课程周几选择与首页排序的交互修正。

- 课程编辑里的每周上课日改为单行胶囊按钮，周一至周日不再被固定圆形宽度挤成两行；选中项使用浅色底和强调边框。
- 「自定义首页」的模块行增加 ⠿ 拖动手柄，可直接拖动排序；原有上移／下移按钮保留，便于键盘或不便拖动时使用。
- 拖动只在同一区域（主区域或侧栏区域）内生效；松开后立即保存顺序，其它布局偏好不变。
- 不修改课程、课时、任务、习惯或已有首页数据。

验证：TypeScript、构建、完整测试。拖动排序依赖 HTML5 拖放，当前没有浏览器控制工具，真实拖动手感和周几按钮在窄屏下的换行仍需刷新页面确认。仅本机更新，未公开发布。
