# Time Desk 0.9.4

首页三个容易混淆的模块重新分工。

- 「本周目标」改名为「本周习惯目标」，只展示每周完成几天这类习惯目标；隐藏该模块后不会再从「今日习惯」里出现。
- 「截止提醒」改名为「待办截止」，只回答哪些未完成待办已逾期、今天截止或 7 天内截止，并标注“已逾期 N 天 / 今天截止 / 还剩 N 天”。
- 「近期提醒」改名为「未来安排」，只列未来 7 天需要按时间参加的日程：有时间的任务、全天日程和课程；按实际发生日期和时间排序。
- 只有截止日期、没有安排时间的待办不再进入未来安排，避免和待办截止重复；请假或取消的课程不显示，调课后的课程按新日期显示。
- 未来安排最多显示 5 条，更多时提供「查看日历」；点击任务打开原任务，点击课程打开课程详情。
- 课前通知与倒计时提醒的设置不变，隐藏未来安排不会关闭已经设置的通知。
- 已有首页顺序和折叠偏好继续兼容，模块 id 不变。

验证：211 项自动测试，新增截止天数、未来安排排除纯截止待办、调课课程与请假课程筛选、7 天边界和排序测试；类型检查、构建通过。当前没有浏览器控制工具，实际列表观感仍需刷新页面确认。仅本机更新，未公开发布。
