# Time Desk 0.8.0

复盘从一个打卡按钮变成可写内容、使用个人模板、可选次日完成和精灵辅助的流程。本版先本机验收，不自动公开发布。

## 复盘内容与模板

- 完成方式为“保存日复盘后自动完成”的打卡型习惯进入专用内容编辑器。其他手动习惯保留打卡方式；数量／时间目标不靠复盘自动完成。
- 与「回顾」页面共用同一份日期笔记。已有内容打开后继续编辑，不另建重复笔记；写一句回答即可，空白或只有模板问题不能完成。
- 一份个人默认日复盘模板，每行一个问题，最多 8 行、2000 字；没有个人模板时显示内置三个问题。模板只保存问题，不从回答里自动提取。支持编辑、恢复默认和自由书写。
- 模板编辑与当天回答分开，保存模板不清空回答。复盘草稿在本次页面按日期保留，切换日期或关闭再打开可继续；刷新前请保存。
- 保存复盘检查该日期的记录版本。另一窗口写过后不直接覆盖，保留草稿、展示最新内容，并提供核对后保留草稿或改用最新内容的选择。个人模板编辑也检测冲突。

## 允许次日完成

- 规则中新增 allowNextDay，旧规则默认 false；新选“每日复盘”模板预填 true，保存前可关闭。现有习惯不自动改规则。
- 不分早晨或晚上，没有具体时刻设置或提醒。开启后按工作台时区直到次日全天结束仍算按时，归属原日期；超过后完成记“补做完成”。
- 超过窗口而没有记录显示“未记录”，不等于用户明确标记的“未达成”。跳过和未达成标记可先撤销再补复盘。
- 今日只额外带出昨天允许次日完成且仍未完成的事项；更早记录留在习惯页，不无限堆积。
- 首次完成时间与最后编辑时间分开。修改日复盘不重置完成时间、不重复生成打卡；修改习惯规则继续按 effective 生效，历史规则保持不变。
- 习惯页日期格区分按时与补做，补做用虚线描边，悬停可见状态。数量与分钟累计仍按实际达到目标的记录时间计算。

## 时间精灵辅助

- 主动点击“请时间精灵帮我复盘”才使用 DSH 默认模型。将所选日期、个人问题、当前草稿和有界的参考记录带入独立复盘会话。
- 每次一个问题，通常两三个；已有回答不重复问，允许简短结束。不把没有记录理解成没有做事，不虚构情绪或成果。
- 复盘 Agent 的 life_desk 工具被作用域内的草稿工具覆盖，只有 draft 操作；不能保存正式复盘、直接打卡或修改任务、模板与设置。
- 模型生成的是候选草稿。用户点击使用后可继续编辑，最终点击保存才写入正式笔记和关联打卡；生成或使用草稿本身不完成习惯。
- 支持停止生成、失败重试，同一请求重试不重复发送。普通精灵会话不被复盘助手覆盖。

## 兼容与隐私

保留 schemaVersion 1，以可选字段兼容已有习惯、日志和复盘。个人模板随主数据备份；助手聊天与候选草稿在独立单元／DSH Session，不进入工作台 JSON 备份，也不进入仓库或发行包。现有记录不会因为本版安装而自动完成、重写备注或开启次日窗口。

修复今日页折叠组件定义在 App 渲染函数内的问题，避免数据刷新时组件重建导致折叠状态复位。

## 验证范围

自动测试覆盖午夜边界、夏令时自然日、次日晚间完成、窗口后补做、未记录与未达成区别、历史规则、模板隔离、版本冲突、首次完成时间、草稿专用工具及请求重试。真实 DSH Storage／HostConnection 验证模板持久化、内容保存、重复打卡防护、冲突与重开。

当前无浏览器控制或可调用的子代理委派工具，由主代理完成源码 UX 复核；真实弹窗、键盘焦点、窄屏和深浅色布局仍待页面验收。模型流程以合成 Agent 事件测试，未发起真实模型生成，不能把这些测试当作提问质量验收。
