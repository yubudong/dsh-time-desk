# Time Desk 0.10.0

本地课程、账本、草稿和备份可靠性完善。仅本机验证，不自动公开发布，不接入同步或服务器。

## 账目正确性

- 多轮“上课—撤销—更换扣课时数量—再次上课—撤销”准确返还本次扣减，每笔返还有原扣减 ID；兼容没有新关联字段的旧日志。
- 系统扣减和返还不能直接新增、修改或删除，避免误删返还改变余额；普通余额调整必须填写原因。
- 课时按六位小数精度累计，避免 0.1 + 0.2 一类浮点误差。净已用课时扣除返还，原始流水继续保留。
- 有账目、出勤或有效期历史后，不能直接切换课程管理方式；需要新建另一门课程，避免旧账被新规则误读。
- 请假默认不扣，机构确实收费时可勾选并指定数量，产生可撤销的系统流水；不计为实际上课。
- 不会自动改写旧版本已经产生的异常流水或擅自调整余额。若曾使用旧版反复撤销并改变扣减量，需核对原始流水，再用带原因的调整记录更正。

## 排课和时间

- 新建未选星期的单次课程在开始日期生成一节，可直接显示、调课和确认。
- 已有课程改变星期、时间、时长、地点、结束日或默认课时，必须选择今天或以后的生效日并确认；保留旧排期、已确认记录和已有单次例外。
- 分星期时间贯穿确认上课、请假、调课和恢复，单次记录冻结实际时间和时长；只剩一个有独立时间的星期时，编辑器仍显示该覆盖时间。
- 单次调课、请假、恢复、上课及撤销保留变更记录，可在详情回查。
- 时间冲突包含同门课其他节次和跨午夜时段，单次调课/加课可在明确确认后继续；长期周课的全周期冲突仍应结合课表核对。
- 不能提前确认未来日期已经上课。

## 提醒与年卡

- 仅填写分星期时间、默认时间为空时也可提醒；跨午夜、提前一天及较长提前量按每节实际时间计算。
- 调课提醒正文显示实际新时间；单节遇到夏令时不存在的当地时刻时，不中断其他课程提醒。
- 年卡修改只检查原属于该周期的上课记录，不因其他周期记录误拒绝；过去有效期、当前周期和续期记录仍分别保存。
- 到期周期编辑优先使用已有周期，不无意新建重叠周期；尚未开始的周期明确显示状态。
- 有效期提示可关闭或选择提前天数。期限课程的课时数是实际上课累计，不是可消费余额或购买上限。
- 系统通知仍依赖 DSH、页面连接和操作系统授权，退出或休眠不保证送达。

## 草稿、历史与首页

- 新增课程、编辑、调课、上课确认、充值及周期表单保留本机浏览器草稿，关闭或刷新后可继续。存储被阻止时退化为当前页面内存并提示。
- 保存失败保留草稿和同一请求 ID；记录在另一窗口改变时先核对，不能直接覆盖；保存期间禁用表单控件。
- 课程详情提供日期、状态、周期筛选与分页，可补记过去待核对的课；同时显示单次变更和长期排期历史。
- 自定义首页拖动和箭头排序只改变该分区，保留另一分区的顺序；跨区和外部文本拖入不写入排序。
- 今日计划、专注、习惯、本周习惯目标及未来安排也遵从持久化折叠状态；隐藏专注后首页窄屏顶部计时器不额外出现，计时本身不因此结束。

## 数据与工具

- 保持 schemaVersion 1，新增字段提供默认值；旧数据可读取。新版备份应使用本版或后续兼容版本恢复，不建议降级后导入含新字段的备份。
- 备份校验返还对应关系、重复返还、排期顺序、周期与课程关联；非法备份在写入前拒绝。
- 恢复时更新数据恢复标记，课程旧草稿需重新核对，即使记录版本号碰巧相同也不会直接覆盖恢复结果。
- 修复课程动作未进入 Agent 工具 action 清单的问题；补齐实际动作说明。设置等写入回执不再返回 undefined，避免“写入成功但工具报 lossless JSON 错误”。
- 浏览器草稿独立于主数据，不进入 JSON 备份；无新增网络遥测或同步功能。

## 验证及边界

- 233 项自动测试，包括先失败后修复的 11 个课程可靠性场景、变更后的历史保持、旧日志兼容、幂等返还、精度、草稿存储失败、分区排序、年卡、完整备份恢复和恢复后旧草稿拦截。
- 使用真实 DSH JSON Storage 与 HostConnection 在合成数据上验证不同扣减量的返还、审计关联、排期历史、完整恢复、重开、工具 action 与 lossless JSON 回执。
- TypeScript、Host/Client 构建和发行文件隐私检查；没有用真实个人数据做写入测试。
- 当前没有浏览器控制或 Windows 实机环境。Mac/Windows 页面点击、草稿恢复体验、键盘焦点、拖动手感、深浅色和系统通知仍需实机验收。自动测试和插槽注册不代表这些验收已通过。
