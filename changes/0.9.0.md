# Time Desk 0.9.0

课程表、课时账本和首页模块化。本版先在本机验收，不自动公开发布。

## 课程表

- 课程按上课人分开：自己和孩子可以各自有课程，不需要创建账号。
- 支持固定周几、开始日期、可选结束日期、开始时间与时长；未选周几时作为单次课程。
- 一周可有多节同一课程；支持请假、临时加课和单次调课，不与原定日期重复计入。
- 调课只改选中的这一节，下周及以后仍按每周安排；可以再次调整或恢复原安排，并保留“原定某日”的记录。
- 首页的今日课程、课程页、周课表和日历读取同一份安排；调课会改变显示日期和提醒时间。
- 课前提醒可选关闭或提前若干分钟。提醒沿用 DSH 页面通知，依赖 DSH 运行、页面连接和系统通知权限，退出或休眠时不保证送达。

## 课时包

- 每门课程独立记账。充值、赠送、首次余额和调整都形成流水，余额由流水累计，可以追溯每一笔来源。
- 首次使用可直接填写“目前还剩 N 课时”，不要求补录以前的所有充值和上课记录。
- 点击已上课并确认后才扣课时；每节默认扣除量可设，确认时可修改。时间过去不会自动扣除，未确认的课保持待核对。
- 请假默认不扣；误标请假后仍可改为已上课。撤销上课会返还课时并保留一条更正记录，不会删除原始扣减。
- 余额不足时提示；实际已上课可以再次确认后记录，余额允许为负并明确显示。
- 充值可选有效期，仅作到期提示，不自动清零课时。可设置剩余课时提醒阈值。

## 包年期限课程

- 选择“期限课程”后必须填写有效期；排课只在有效期内生成，到期后不再新增课程安排。
- 本期统计只计算实际上课的次数与课时，按实际日期归入对应周期；请假和未确认记录不计入。
- 缺课不会自动延长期限，也不会因为到期把没上的课算作完成。
- 续期在同一课程下新增周期，旧周期的记录和统计保留；到期前可提前提醒。
- 补记或更正上课按实际上课日期归入周期；调到下一期时，需要该日期已在新周期内，否则会提示先续期，不把调课当作自动延期。
- 有效期不能缩短到排除已上课记录，周期之间不能重叠。

## 首页模块

- 今日计划、今日课程、重点、定时安排、计划待办、延续待办、截止提醒、更早已发生、已完成、收集箱、专注、习惯、本周目标和近期提醒都可以隐藏、排序和折叠。
- 隐藏会移除整个模块及留白，但不删除任务、课程、习惯或账目；仍可从侧栏进入对应页面。
- 折叠状态和布局随工作台数据保存，刷新后保持。可一键恢复默认首页；所有主模块隐藏时显示恢复入口。
- 隐藏模块不改变今日计划的负荷统计；隐藏习惯时本周目标的位置仍可单独控制。
- 现有用户升级后保持默认全显示，首次保存首页设置时才写入布局偏好。

## 数据与兼容

- 保留 schemaVersion 1；新集合和首页偏好都有默认值，旧数据与旧备份可以直接读取。
- 课程、周期、单次调整和课时流水进入工作台 JSON 备份；助手聊天与候选草稿仍不在备份中。
- 时间精灵新增 lesson、lessonTerm、lessonSession、lessonCharge 操作：可以读取和录入课程与充值；确认上课、删除整门课程、批量调整或更正账目仍需明确同意，不猜上课人、价格或有效期。
- 新增数据不改变计时、任务、习惯和复盘的既有行为；课程不参与番茄钟自动完成，也不自动从专注记录扣课时。

## 验证范围

- 自动测试覆盖固定周课、单次调课不重复、恢复原安排、请假后改上课、时间冲突确认、课时扣减与撤销、余额不足确认、充值更正、期限边界、续期与旧周期统计、首页隐藏/排序/折叠和旧数据默认值。
- 真实 DSH JSON Storage 与 HostConnection 使用合成数据验证课程创建、充值、上课、重复确认拦截、撤销、调课、恢复、期限越界拒绝、首页偏好持久化与重开读取。
- 当前没有浏览器控制工具；本版由主代理做源码级 UX 复核，未实际点击页面。周课表在窄屏的列数、弹窗键盘焦点、深浅色细节和真实系统通知仍需页面验收。
