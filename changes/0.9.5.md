# Time Desk 0.9.5

同一门课程支持不同星期使用不同上课时间。

- 课程新增可选的「分星期上课时间」：选中两个及以上星期后，会为每个星期显示单独的时间输入。
- 留空的星期使用「默认上课时间」；例如周三 19:00、周日 10:00，可只给周日填 10:00，周三沿用默认 19:00。
- 单次调课仍以实际调后的时间为例外；调课不会改写每周的分星期时间。
- 课程详情、课程卡片、今日课程、周课表、日历和课前提醒都按每个星期实际时间计算。
- 课表冲突检查也使用分星期时间；同日同上课人时间重叠时仍会提示。
- 旧课程默认没有分星期时间，继续使用原来的单一时间，兼容旧数据与备份。
- 时间精灵可传 `weekdayTimes=[{weekday,time}]`，其中 weekday 必须属于已选星期。

验证：新增分星期时间生成、周标签和非法星期拒绝测试；类型检查、构建、完整测试通过。当前没有浏览器控制工具，分星期输入的实际布局仍需刷新页面确认。仅本机更新，未公开发布。
