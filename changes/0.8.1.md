# Time Desk 0.8.1

习惯列表采用更紧凑的名称与进度排版。

- “按时完成”“1000/1000 个”“每周次数 · 0/3”等小字移到习惯名称右侧，以文字基线对齐，保留原有 11px 字号与颜色，不再默认占一整行。
- 名称和状态在宽度不足时允许自然换行，打卡按钮保持固定尺寸，不压缩、不覆盖文字。
- 习惯整页的日期行上边距从 12px 缩至 6px，下边距归零；习惯行上下内边距从 9px 缩至 8px。日期按钮的点击尺寸不变。
- 只限定习惯行样式，普通任务名称与下方日期／截止说明保持原样；不改变习惯数据、复盘、打卡、计时或规则。

## 自 0.6.0 以来的主要更新

- 侧栏快速记录、快捷键、收件箱整理与今日计划：可选择延续事项，设置可用时间并查看已估时负荷和未估时数量。
- 习惯支持时间目标、可选模板、简洁平铺和折叠的今日分区；移除旧的时段分组。
- 日复盘支持个人默认模板、自由书写、可选次日全天完成，以及时间精灵提问并整理候选草稿；用户确认保存后才写入复盘和关联打卡。
- 改善升级快照持久化和并发检查。数据备份不包含助手对话与候选草稿；复盘模板随主数据备份。

## 验证范围

此前 0.8.0 已通过 180 项自动测试、类型检查及真实 DSH 存储与路由的合成数据验证；本次排版变更通过 TypeScript、Host/Client 构建和隐私检查。真实页面的窄屏排版与模型提问质量仍需实际交互验收。
