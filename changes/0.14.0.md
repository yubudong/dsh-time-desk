# Time Desk 0.14.0

## 延续待办拖入计划待办

- 桌面端支持从延续待办任务标题、行空白或左侧六点把手拖动，放到「计划待办」即加入当前所选日期；沿用原有plan pick操作，不改原安排日、截止日、完成状态或发生实例。
- 拖动时显示来源淡化、计划区高亮和放置提示；计划区即使为空或已折叠也可作为落点。悬停时临时展开，保存成功后保持展开以显示结果，不改写用户保存的折叠偏好。
- 保留加号按钮和移回待选按钮；复选框、重点、计时和编辑操作不会作为拖动起点。未使用拖拽时不额外占据首页空间。隐藏计划区后不显示拖拽把手。
- 放到其他位置、Escape或窗口失焦只取消本次拖拽；保存失败保留原任务和服务返回的错误，不乐观移动数据。原生拖拽载荷只包含本页面随机标识，不携带任务标题或内容。
- 放下时重新核对所选日期、revision、dataEpoch和最新待选实例；外来载荷、旧快照、日期切换、备份恢复及已选/已改期任务不能通过旧拖拽写入。重复请求使用稳定requestId去重。

## 验证与边界

- 264项自动测试，类型检查、Host/Client构建与隐私检查；8个新增回归覆盖日期保持、外来/取消拖拽、旧版本/恢复失效、忙碌保护、实例资格、重复请求、移回及服务持久重开。
- 真实DSH存储与HostConnection合成业务回归通过，不使用用户真实记录做拖拽测试。
- 没有可控制浏览器的工具；Electron/Web实际鼠标拖动、自动滚动和窄屏高亮仍需界面实机验收。加号是键盘及不使用原生拖拽时的保留入口，不承诺触屏拖拽。
- 本轮仅更新本机，不推送GitHub、npm或市场，不覆盖已公开0.13.0。
