# Time Desk 0.7.1

统一快速录入入口，消除“快速记录”和“快速新增”的选择歧义。

- 移除顶部重复的全局新增按钮；左侧统一为“快速记录”，折叠或窄屏时保留加号、提示与可访问名称。
- 左侧按钮与工作台内 ⌘/Ctrl+Shift+K 打开同一个轻量面板，默认进入收件箱，不随当前页面自动切换归属。
- 可展开设置项目、日期与估时，也可点击“详细编辑”，携带当前内容设置重复、提醒、子步骤等。
- 转入详细编辑时不写入任务；保存成功后清空快速草稿，取消详细编辑回到原快速草稿（详细编辑中的未保存改动沿用现有放弃确认）。
- 项目、日历和生活页面里的局部新增继续使用所在页面上下文。
- 关闭快速面板后焦点回到左侧按钮；完整编辑的同一请求重试保留请求标识。

不改变存储结构、现有任务、计划和计时。仅本机更新，未公开发布。

验证：类型检查、构建与既有回归测试；主代理完成源码层面 UX 复核。没有浏览器控制工具，因此真实点击、焦点与窄屏显示仍待页面验收。
