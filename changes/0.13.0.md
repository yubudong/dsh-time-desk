# Time Desk 0.13.0

## 简化首页

- 删除首页“今日计划”统计卡的组件与渲染：已估算分钟、未估时数量、已记录专注分钟、可用分钟输入/保存和相关说明不再常驻首页。
- 删除自定义首页中对应模块；活动模块从14个减为13个。删除该卡专用样式和中英文文案，不改名隐藏、不另建入口。
- 时间精灵及业务工具说明不再引导设置每日可用分钟或维护预算，查看今日仍可读取重点、定时事项、待办和延续待选。

## 保留的日常能力与数据

- 今日重点、定时安排、计划待办、延续待办的加入当日/移回待选、课程、习惯和番茄钟均保留。
- 任务的预计分钟/番茄数字段、专注历史、已经选入某日的延续任务及其他工作台记录不删除。
- 旧布局中已存的 `plan` 标识继续可读，只作为退役标识，不再渲染或出现在自定义选项中；升级和旧备份恢复不因它报错，也不重置其他模块顺序、隐藏或折叠设置。
- 已有 `dayPlans.availableMinutes` 和旧接口数据仅为历史/备份兼容保留，不再作为可见功能推荐或引导。没有通过迁移批量改写用户数据。

## 验证

- 256项自动测试、类型检查、Host/Client构建及隐私检查。
- 新增旧版布局/备份回归：恢复后退役卡片不再出现，已选入当日的任务仍在，任务估时、原日期/截止日、专注日志和其他布局偏好保留；持久重开可读取。
- 真实DSH存储与HostConnection业务回归继续验证历史接口和选入当日机制。当前无浏览器控制，实际首页留白与页面点击仍需实机确认。
- 发布包用于GitHub、npm和市场版本更新；市场收录和审核状态独立于代码发版。工作台记录、精灵聊天、私有配置和个人截图不进入源码或发行包。
