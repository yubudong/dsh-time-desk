# Time Desk 0.7.4

彻底移除习惯的“时段”字段，不再只是界面隐藏。

- 习惯数据结构不再包含 `period`。界面、模板、默认值和文案中的“不限／早晨／晚上”一并删除。
- 启动时检测旧数据：如果仍有 `period`，按当前 schema 规范化一次并写回，revision 加一；再次启动不会重复加。
- 恢复旧备份同样会去掉该字段，其余习惯名称、规则、关联复盘、打卡记录保持不变。
- 删除后的旧备份仍可导入；新导出的备份不再带该字段，旧版本插件读取新备份时该字段自动缺席，不影响其他内容。
- 时间精灵与 `life_desk` 工具的习惯字段说明同步更新，不会再把该字段当作可设置项。

验证：类型检查、构建、158 项回归测试。新增测试覆盖旧数据一次性清理、二次启动不重复加 revision、旧备份恢复后字段消失且关联保留。没有浏览器控制工具，真实页面显示仍待验收。
